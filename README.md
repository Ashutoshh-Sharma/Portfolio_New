# Ashutosh Sharma — Portfolio

## Run locally
1. Extract the project.
2. Open the folder in VS Code.
3. Start `index.html` with Live Server, or serve this folder with any static web server.

## Files
- `index.html` — page structure and metadata
- `css/style.css` — theme, layouts, responsive rules and animations
- `js/script.js` — interactions, card flip and UI behavior
- `assets/favicon.svg` — site icon

## Profile card
The profile card uses a dedicated 3D inner wrapper. Flip it to reveal clickable email, GitHub and LinkedIn links, plus location details. The transparent desktop navbar and readable mobile menu are retained.
